# Monster Exchange Battle Sprites v1

Battle-sprite pack for the 90 monsters shown across the first six supplied card sheets.

## Included

- 90 monsters
- 4 poses per monster: `idle`, `attack`, `hit`, `defeated`
- 360 transparent 256×256 PNG source sprites
- 360 transparent 128×128 runtime sprites
- 40 transparent evolution-line or single-species sprite sheets
- Complete contact-sheet preview
- `sprites.json` manifest
- `INTEGRATION.md` implementation guidance

Tusslegrub's line is complete with Rooklimb. Simiri now has nine permanent elemental branch outcomes: Fire, Water, Grass, Electric, Ice, Ghost, Dark, Steel and Psychic.

Water-species anatomy is checked pose by pose: tails must connect at the rear pelvis and remain visually separate from head fins, crests and ears.

The original sprites face left. Mirror them horizontally in code when a player-side monster should face right.
