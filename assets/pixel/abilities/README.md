# Ability artwork v1

Generated with the built-in image-generation tool. The unchanged transparent atlas is ability-atlas-v1.png. It covers the 43 current runtime skills, ten statuses and shared passive/shield/recovery symbols. Passive identities retain native names but share one symbol; this is not 244 bespoke passive illustrations. Workbook skills not yet imported into runtime are outside this coverage. No bespoke attack VFX sequences are included.

Atlas mapping: src/ui/ability-visuals.ts. Android renderer: mobile/AbilityIcon.tsx. Measured row boundaries accommodate the generated composition rather than assuming perfectly equal cells. Phone-size visual QA is still required; the generated atlas is not a certified 32px logical pixel master.
